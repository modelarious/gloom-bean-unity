# Delivery plan

1. Reusable native Unity foundation and an isolated mechanics playground/campaign. Commit/tag `foundation-v0.1.0` before adding possession mechanics.
2. Gloom Bean atlas implementation layered through foundation extension points, data and authored rooms. Preserve the exact source PDF and explicit unimplemented/experimental boundaries.
3. Real Windows Unity import/build/runtime checks. Correct bugs using logs and physical tests. Publish source, native build and separate checkpoint archives.

No changes to existing DungeonForge source repositories, no Nintendo assets, no paid agents, no new authorization prompts. Installed Windows Unity version is 6000.5.9f1. Counts are configurable; atlas is five worlds × four levels followed by a boss. The user's phrase "4 worlds then a boss" is interpreted in light of that explicit atlas structure, not as authority to silently discard a world.
