# Reachable physical paths
The return now demonstrates opposite-pole catches using the lower, descending jumping line rather than forcing high launch arcs through optional orbital scenery. The game geometry still permits those expert arcs; no exit condition or save requirement changed. The moving Mercy gets a separate visible side launch coil directly below its orbit, retaining the same existing force law. Noon screens were blocked by their own eight-metre shutters; their rails now pass above six-metre shutters, still well above ordinary jumping. This fixes real geometry instead of teleporting the screen or granting its latch.
