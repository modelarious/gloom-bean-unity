# Orbiting Mercy implementation
The L17 Mercy is now inside a real moving open-ring collider, not on a static ledge. Its opening moves with the orbit; two fixed opposed iron masses above it alter the Host's approach. The test uses actual coil power, jumping, steering and polarity exchange, then must physically leave the ring and return to the course. This secret is not accepted until that route passes. Separately, the last return may land on the real entrance floor rather than unnecessarily recatching its elevated training dock; the exit and save still must be reached normally.
