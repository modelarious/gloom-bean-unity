# Hanging screen and loose bell: physical cable module
The new CablePulley is a unilateral, routed, mass-weighted impulse constraint. Gravity on a loose bell raises a screen through a world-supported cable; slack stays slack and endpoint positions are never overwritten. This supports the atlas L17 bell/screen momentum puzzle without a hidden switch moving a platform. A production-component fixture measures real deck rise, bell fall and bounded extension. Integration and native acceptance are still pending in this commit; no level or secret is newly certified by code presence.
