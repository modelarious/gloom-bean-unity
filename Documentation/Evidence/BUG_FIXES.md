- Conveyor speed was added every physics tick. It is now a support-relative target; a native bound/displacement test covers the fix.
- The restoration ending accepted a count of prefix-matching secrets. It now requires all 20 exact unique Mercy IDs.
- A partial Coffin cure left the altered capsule dimensions behind. It now restores ordinary dimensions even while another tenant remains.
- Shadow body movement silently snapped a distant shadow home. The physical body is now constrained by the tether instead.
- Sunday Best initially had return platforms that blocked opening jump clearance, and the optional secret jaw gated ordinary return. Input-only traversal exposed both. Return-only geometry changes with the Turn, and the Mercy route is now above the ordinary exit route.

Explicit enableCollision on both chandelier and Marionette restores world contacts. The final probe hit the actual target at 7.73 m/s relative speed; no direct boss-state call was used.
