# Foundation iteration update

This branch contains only reusable platformer systems, not the Host Cycle campaign or possession implementations. Original foundation-v0.1.0 and foundation-v0.1.1 tags remain unchanged.

New reusable pieces: one-way landing surfaces, safe static-layout JSON overlays, shared world/level/boss progression predicates, original low-volume procedural action cues with F4 mute, nonsingular sprite transforms, and independent native iteration tests. The public replica snapshot hook remains inert unless a later campaign uses it.

Use Gloom Bean > Campaign workbench > Edit layout to pause a rebuilt practice course, select supported static boxes, move/scale them in Scene view and Save static layout overrides. JSON is written below Assets/GloomBean/Resources/LevelLayouts. Dynamic machinery and scripted semantic objects stay code-authored. Stale source fingerprints reject the whole overlay. Always re-test reachable routes after geometry or tuning changes.

Native acceptance of this exact foundation update is pending until its own clean import/build and Mechanics suite complete. Do not substitute the earlier 44-pass report for this version.
