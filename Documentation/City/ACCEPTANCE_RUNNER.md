# Earned chapter integration runner

Tools/Run-Campaign-Acceptance.ps1 accepts a pinned fresh-clone configuration. It validates the actual engine input tree is committed before and after build/testing; owns subprocess timeouts; emits a persistent runner receipt; and copies only an actually earned parent save to its child. No arbitrary extra commands or free-form CLI flags are accepted in a case.

Every positive case requires a native exit code 0, zero failures/exceptions and a non-empty assertion set. A rejected unearned-world case has a separate explicit expected-failure oracle. Tests do not certify human feel or final art. The script must run through the existing licensed desktop-user scheduled-task route, never SYSTEM.

This adds the missing W1 -> W2 -> W3 ordinary and all-secret chain without requiring another new execution service. World 4/5 enum modes are reserved for actual future witnesses; absent witnesses must fail rather than becoming coverage evidence.
